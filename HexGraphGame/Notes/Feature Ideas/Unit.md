Make units that can be pieces on the board. They should be selectable, moveable, obey pathing rules (dont phase through walls, etc.)

Should be a base class that could be extended so that units could have unique behavior and stats

# Unit type Ideas
- Flying
- Teleporting
- Each unit should have stats that vary (damage, move speed, health, special abilities, etc)
- Big powerful pieces with large costs
- Small weaker pieces that are cheaper but do good in mass
- Board manipulation (change a type type, alter benefits of a tile, swap tiles, etc)
- Units that require certain tile adjacencies in order to be created
	- Example: You have a Wizard academy tile that can create apprentice wizard units. But this academy can create increasingly stronger wizard units for each adjacent tile with Mana Sources or something
